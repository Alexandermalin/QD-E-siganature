# 开发批次与依赖

实施采用小批次，每批都核对新增/修改文件、接口兼容性、异常、事务、编译及可运行测试，并更新 TASK_TRACKER、CHANGELOG、TEST_REPORT、UNRESOLVED_ISSUES。禁止把待实现目录或纯模拟结果计为 NC 功能完成。

| 批次 | 交付与主要类/配置 | 依赖 | 本批验证 |
|---|---|---|---|
| 01 工程与数据库 | 六模块源码根、隔离构建、版本化 SQL、15 份开发文档、243 行范围目录 | 原 JDK7、NC Home 只读依赖 | 示例基线、CSV 243/35及唯一性、SQL静态检查 |
| 02 上下文与策略 | OperationContext、BusinessObjectRef、PolicyDecision；IPolicyService/IOperationService；请求/策略存储 | qd_es_control/node/policy/request/object | 四种组合、默认关闭、BU隔离、请求幂等 |
| 03 客户端公共拦截 | NC ActionInterceptor、新增插件绑定、适配注册；不覆盖产品类 | 正式节点动作映射、服务接口 | 失败终止、取消、重复点击、保留原异常处理 |
| 04 窗口与认证 | 原生签名窗口、ISignatureService、baseapp认证桥 | 当前NC会话、真实密码错误计数/锁定接口 | 成功/失败/锁定/取消，密码不落盘，不能切换用户 |
| 05 签名与关联 | SignatureRequest/Result、对象展开、真实编码回写 | qd_es_signlog、对象及请求定位 | 一次批量认证、多对象日志、回滚后保留签名 |
| 06 新增/修改/删除 | 服务端适配、快照、差异 | 真实业务事务和完整聚合对象 | 表体增删改、敏感字段排除、删除回滚 |
| 07 状态与特殊动作 | 审批/弃审/签字/取消签字、分配/批改/开关/数电/复合库存 | so/pu/purp/ic真实扩展入口 | 清单逐行验证、部分成功、外部待核对 |
| 08 查询与导出 | 查询窗口、QdLogRepository、CsvLogWriter | 权限与授权组织、在线历史表 | 同筛选同权限、跨月分页、中文/公式/大数据 |
| 09 归档与安全 | MonthlyArchiveStore、后台任务、安全事件桥 | 平台任务注册、预建月表、独立安全规则 | 北京时间边界、缺表失败、防重重跑、历史一致性 |
| 10 NC联调交付 | 注册与部署包、回归报告、逐行验收 | 可连接的测试库及可运行NC客户端/服务端 | 243操作、原业务回归、权限/事务/安全/异常全链路 |

所有正式范围均保留在配置及台账，不以代表节点替代完整验收。两个待辨认节点不妨碍公共核心开发，但不能从分母剔除。SQL 先形成可审查脚本，确认后才在测试环境执行；生产库、生产配置、核心依赖升级和删除原文件需另外授权。
