# 基础档案集团策略和物料全字段审计验收

## QDNC 准入

只读预检已确认 QDNC 仍为 1.1.0，当前无待确认、待执行或执行中请求。物料集团节点为 `10140MAG`，物料业务单元节点为 `10140MAO`。集团节点仍使用 NC 原生配置，业务单元节点已使用既有试点配置。现场库的 `bd_materialconvert` 以 `pk_material` 关联主档，辅助单位行有独立的 `pk_materialconvert`。已查询到集团物料使用 `pk_org = pk_group`。

共享测试库使用维护窗口。冻结新请求，排空执行中请求，备份受影响的项目文件及 NC 节点配置，隔离测试账号、物料编码和外发任务。集团总控初始关闭。先核对新增和修改的原生基线，再由测试账号启用本轮验收动作。

1. 先执行 `group-base-policy` 中的只读预检，再按目录顺序执行集团策略升级。Oracle DDL 单独执行。策略迁移和 NC 菜单注册分别核对后提交。
2. 安装与数据库升级配套的候选包。执行 `management-menu/06_register_group_policy.sql` 注册集团策略页及集团签名、审计日志权限。通过 NC 权限维护分配独立的 QUERY、SAVE、MASTER 和集团日志 QUERY、EXPORT 权限，刷新原生权限缓存并重新登录。
3. 按 [物料集团保存试点](MATERIAL_GROUP_SAVE_PILOT.md) 接线。只配置已有可执行适配的动作。总控开启前逐项核对实际节点、按钮、允许的操作类型和接入状态。

## 首批核对

| 用例 | 应核对的结果 |
|---|---|
| 集团策略与业务单元策略 | 集团页按动作显示 77 项，业务单元页显示其余 166 项。对未接入动作仍可查看接入状态。旧业务单元策略接口拒绝保存基础档案项。 |
| 权限与版本 | QUERY、SAVE、MASTER 独立授权。两个获准业务单元执行已接入的同一动作时读取同一集团配置。其他集团配置隔离。改总控或按钮后，原待确认或待执行授权失效。 |
| 集团物料新增 | 选主单位并保存确实产生辅计量行的样本。用请求号联查同一条审计的主档及辅计量 AFTER 快照，分别核对表名、行主键、物理字段编码、保存值及空字段。 |
| 集团物料修改 | 用同一物料只改辅计量行。前后快照各保留实际列，差异定位到 `bd_materialconvert` 和具体行。签名开启、仅审计、仅签名和两项关闭分别执行。 |
| 取消和回滚 | 取消签名、原生校验失败以及隔离环境下注入审计写入失败。核对业务数据及成功审计的提交或回滚，独立签名结果保留。 |
| 日志授权与长值 | 只有业务单元权限的账号无法读取集团日志。分别用集团查询和导出权限测试列表、明细、联查、导出和归档数据。对超出列表预览的快照读取完整值，并核对旧快照兼容。 |
| 分配及独立页签 | 以财务组织、采购组织和分配目标组织为独立验收维度。仅在对应最终写入路径接入后执行。分配需核对单目标、部分成功、已分配和失败回滚。 |

逐用例记录测试账号、节点、物料编码、请求号、审计编号和结果。部署脚本、按钮登记和离线测试都单独记为接入证据。现场验收计数以通过的真实 NC 操作为准。

撤回时先关集团总控并排空请求，执行 `group-base-policy/04_prepare_rollback.sql` 停用集团映射和旧业务单元策略，按部署记录恢复原生节点路径和模块补丁，保留新增期间的请求、签名和审计证据。集团菜单撤回前先撤回新增权限，再运行 `management-menu/07_rollback_group_policy_menu.sql`。
