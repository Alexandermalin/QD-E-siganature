# 基础档案电子签名离线候选交付

**离线测试通过，现场联调待完成。** 本包是源码与编译产物的离线候选，不代表基础档案清单全部完成或已通过真实事务验收。本次候选包未部署到 NC，未执行数据库脚本或触发外部系统。

包中 `source/` 包含与构建一致的源码、测试、构建工具、配置和 SQL；`runtime/` 包含 Java 7 JAR、UPM、配置、SQL、文档及构建清单。构建使用 IBM JDK 7 和本机 NC65 依赖；NC 产品文件、凭据及数据库不在包内。`SHA256SUMS.txt` 列出各文件校验值。

本包以此前通过完整离线构建的快照为基线，叠加本批基础档案源码、测试和相关说明后重新构建；工作区内其他模块或构建工具的后续改动未纳入。部署前必须与现场版本及需保留的其他改动逐项合并核对。

本批补充了组织页签受控事务、回执范围绑定、原生调用前后数据源检查，以及客户端分批规划、授权、恢复和结果汇总的候选接线。组织页签的公开入口、签名准备和业务认领仍保留拒绝保护，不能作为已支持的业务功能启用。离线测试使用替身和模拟元数据验证非空页签的部分成功与审计快照，不能证明现场原生服务、真实提交或外部系统回滚。

## 安装与验收

1. 仅在与实际 WMS、OA 隔离的 NC65/Oracle 环境中使用。先核对 NC 版本、已有补丁和策略，备份现有项目 JAR、UPM、客户端配置、数据库结构及签名审计数据。包内包含共享基础服务和其他模块类，须与现场版本逐文件比较，不能直接覆盖已有补丁。
2. 根据 `runtime/release-manifest.json` 确认所需模块 JAR 和 UPM；在停服、备份并核对差异后，按 `runtime/modules/` 的相对路径部署到隔离 NC Home。客户端配置示例不是自动注册，节点及策略需按现场权限和验收计划逐项核对。
3. 逐个审查对应的 `runtime/sql/nc65-electronic-signature/` 脚本和版本依赖。部分旧脚本硬编码了共享测试环境标识，不能用于本次隔离验收；候选脚本中的隔离环境占位符也必须核实后替换。Oracle DDL 会隐式提交，不能将脚本直接用于共享环境。组织页签批改入口当前仍关闭。
4. 在源码目录可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1 -NcHome "E:\NC65\nchome" -Test`，将示例路径替换为实际隔离环境的 NC Home；NC Home 和 IBM JDK 7 作为只读依赖。构建记录及完整离线日志随包提供。现场需另行验证客户端、权限、并发、原生扩展、真实提交与审计回滚，并隔离 WMS、OA 等外部副作用。
