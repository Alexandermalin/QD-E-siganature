- 快速批改结果查询按客户、供应商和物料节点分别校验对象类型，并重新检查当前档案数据权限；组织页签还重验全部目标组织权限。候选客户端丢失原生回执后，在动作清理完成后按请求号只读查询持久化状态，并核对完整授权对象、档案编码、操作组织及批次和逐行状态；已知终态会说明成功、失败和未变化数量，未知或执行中不会宣称已提交或已回滚。恢复窗口可浏览和复制全部逐档案结果，未结束时可重新查询状态；窗口注明执行中或未知状态可能变化。原生返回值缺失时停止后续批次，不自动重试；异常查询、现场权限、事务及外部副作用仍需联调。
- QDNC 只读核查显示活动仓库和货位均属于业务单元。客户、供应商、仓库触发器写入对应的 WMS 下发表。客户保存事件 `1002` 和 `1004` 还登记了 `SyncLepuCustListener`，本地对应源码会直接向乐普 WMS 发送 HTTP 请求。验收需隔离外部发送并分别核实 Oracle 和 WMS 的结果。
- 物料主档删除后会用删除前的行主键复查组织页签是否被转移，并用历史父键复查删除后出现的子行；这不能替代对最终复核与提交之间并发插入的控制。NC 图片目录节点和 UFS 文件版本都可能保留原标识而内容发生变化。后台已比较登记和当前文件元数据，物理清理仍需验证存储支持的条件删除及失败后核对方式。
- 本地接口核对显示，`IFileSystemService.deleteNCFileNode` 和 `IImageSystemService.deleteNCFileVOByPath` 均只接收一个字符串参数，没有提供文件版本或条件删除参数；本机 `uapim` 附带的 UFS SDK `UFSClient` 暴露上传、下载和元数据查询，未暴露删除方法。这些只说明本地依赖的接口，不能推断现场实际存储实现或排除其他服务能力；在可验证的文件级条件删除和并发保护接入前仍不得自动清理。
- 当前没有与实际 WMS 隔离的 NC65/Oracle 验收环境；源码与离线测试不等于真实事务、外部事件或回滚验收。
