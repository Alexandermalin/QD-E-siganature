# 物料集团普通保存测试批次

本批次提供 `10140MAG / Save / INSERT,UPDATE`、`FiSave / UPDATE` 和 `PuSave / UPDATE`，并将 `10140MAO / Save / INSERT` 挂到同一个集团保存策略。集团物料的实际所属组织键等于集团键，业务单元物料使用实际业务单元键。普通保存及页签保存继续调用各自的 NC 原生服务。

普通保存采集实际落库的 `bd_material`、`bd_material_v`、`bd_materialconvert`、`bd_materialtaxtype`，业务单元新增另采集实际存在的本组织 `bd_marorg` 行。财务、采购修改分别采集 `bd_materialfi`、`bd_materialpu` 行，按原生页签权限校验目标组织。涉及同步修改多个物料版本编码、独立辅助属性保存、页签删除以及手工分配和取消分配的路径待接入。

## 安装与配置

1. 在 QDNC 隔离维护窗口核实测试集团 `0001A9100000000005MH`、测试业务单元 `990`、集团节点和按钮授权，并检查现有 WMS 触发器与外发任务。保留原客户端参数和应用补丁备份。
2. 执行集团策略 `1.2.0` 的升级步骤并安装同一个候选补丁的公共、服务端和客户端产物。保留新集团总控为关闭。
3. 在 NC 功能注册中，把 `10140MAG` 的 `BeanConfigFilePath` 从 `nc/ui/bd/material/config/Material_Config_Group.xml` 改为 `nc/ui/uapbd/qd/esign/QdMaterialGroupConfig.xml`。核对 `10140MAO` 使用 `nc/ui/uapbd/qd/esign/QdMaterialOrgConfig.xml`。重启或刷新 NC 配置缓存并重新登录后，核对两节点各自打开正确页面。
4. 关闭自动提交并绑定 `:pilot_group`、`:pilot_mode=REGISTER`，执行 [物料集团试点注册脚本](../../sql/nc65-electronic-signature/material-group-save-pilot/configure.sql)。确认两个节点使用同一正式保存策略且集团总控仍关闭，再提交。
5. 核对财务、采购页签仍可打开并编辑，确认加载了本补丁的两个页签配置后，执行 [页签试点注册脚本](../../sql/nc65-electronic-signature/material-group-save-pilot/register_org_pages.sql)。测试角色需同时具备原生页签目标组织权限。保留集团总控关闭，先验证三条原生保存基线。
6. 通过「基础档案集团策略」仅配置本轮测试的物料保存、财务信息保存和采购信息保存，检查入口和设置后再打开测试集团总控。通过集团业务权限与集团日志权限分别授权执行账号、审计查询账号。

## 验收记录

| 用例 | 核对内容 |
|---|---|
| 集团新增，主计量单位带出辅计量行 | 真实物料主键、编码回填，同一请求和业务审计内有 `bd_material` 与实际落库的 `bd_materialconvert` 的 AFTER 快照。按表、行主键和字段编码核对所有列，包含空值、结构字段和自定义字段。 |
| 集团修改，仅调整辅计量 | BEFORE 和 AFTER 均包含主档与辅计量快照。字段差异归在 `bd_materialconvert` 对应行，包含真实原值和新值。 |
| 财务或采购信息修改 | 通过对应页签的保存按钮发起一次操作。日志以物料编码和请求号关联，快照显示对应物理表、行和实际目标组织。缺少目标组织权限时，受控更新应被拒绝。 |
| 集团修改并发与跨档案行 | 锁冲突阻止保存。签名请求绑定已选物料，替换物料或传入其他物料的明细行应被拒绝。 |
| 签名和审计组合、取消和失败 | 四种开关组合分别验证。取消签名保留取消事件。原生校验拒绝或注入审计写入失败时，用请求号核对失败状态和业务数据未提交。 |
| 业务单元继承 | 用 `990` 入口验证同一个集团保存配置。业务单元日志以 `990` 授权查看，集团日志以集团日志权限查看。 |

使用 [只读验收查询](../../sql/nc65-electronic-signature/material-group-save-pilot/verify.sql)，按请求号保存核对结果。保留上线候选补丁版本、账号、节点、组织、操作、请求号和实际结论。数据库表结构已完成只读核对，真实客户端保存及同事务故障验证以 QDNC 验收记录为准。

## 撤回

测试后按原记录恢复集团总控和按钮开关。若退出本批次，先关闭集团总控和三个试点按钮并排空执行中请求，绑定 `:pilot_mode=DISABLE` 执行普通保存试点注册脚本，使普通保存映射停止受控。完整版本回退时使用集团策略回退脚本，使试点页签映射也停止受控，再恢复客户端参数和补丁。保留签名、审计和快照。
